Política de privacidade

A Shop Shoes é uma loja fictícia criada para portfólio.

O que guardamos

Se você aceitar, o site guarda no armazenamento do seu próprio navegador a lista dos tênis que você viu e uma contagem de preferências (uso, estilo, cor, marca e faixa de preço). Isso serve só para sugerir modelos parecidos.

O que não fazemos

Esses dados não são enviados a nenhum servidor, não são compartilhados e não incluem nome, e-mail ou qualquer dado pessoal.

Como mudar de ideia

Use o link "Preferências de privacidade" no rodapé. Ao recusar, os dados guardados são apagados. Você também pode limpar os dados do site nas configurações do navegador.
